## Verified baseline facts (do not re-derive)

- Full backend suite (`cd backend && CI=1 uv run pytest tests/ -q`) reports **4 known pre-existing failures** — see memory `deerflow-full-suite-known-failures` — the 2 `collab_publish` (order-dependent override leak) and 2 `client_e2e` (stale regex + Docker `/app` path). All **pass in isolation**; the collab ones fail **only under full-suite order**.
- `collaboration/routers/publish.py` uses a **module-global `_service`** via `configure()` / `reset_for_tests()`, and tests override `require_user` through `app.dependency_overrides`. When a prior suite test leaves an override (or `_service`) active, the publish route evaluates against stale state → `publish_actor_user_id` becomes `'owner'` (a role string) instead of `u1`, or a member is allowed (200) instead of denied (403).
- ABAC (`app/gateway/abac/`): `Subject`/`Resource`/`Action`/`Operator`/`AttributePolicy`/`evaluate()`; presets `OwnerOnlyPolicy` / `WorkspaceMemberPolicy`; fixed AST (no `eval`/`exec`). Already wired into `collaboration/routers/publish.py` + `canvas/routers/workflows.py`.
- Quota: `multitenancy/{usage_tracker.py, cost_dashboard.py, routers/api.py}` already expose `aggregate_costs(tracker, group_by)` and `tokens_in_window_for_workflow()`; there is a `GET .../cost` dashboard and `GET /api/admin/governance/cost/tests` etc. `aggregate_costs` already supports `group_by=tenant_id|user_id|model` — issue #11's "per-user/per-workspace" is a thin router + frontend over this existing aggregation.
- Admin nav shell: `components/workspace/admin/admin-page-shell.tsx` seeds `adminLinks`; each page is a route under `app/workspace/admin/`. `secrets-admin-page.tsx` is the four-tab UI template. i18n spans `en-US` + `zh-CN` under `t.admin.*` / `t.workspace.*`.
- Admin secrets: `packages/harness/deerflow/admin/{secrets,audit}.py` — `rotate_env_secret`/`rotate_vault_cipher`/`upsert_secret`, `filter_admin_audit_records`; `routers/admin_secrets.py` rate-limit + allow-list.

## Milestone M4 — Multi-region secret isolation (issue #12)

Vault file is currently a single-local-Fernet file (`admin/secrets.py`). Add an object-storage replicator guard + DR drill. **TDD.**

- [ ] **M4.1:** `admin/replicator.py` — `SecretReplicator` Protocol + S3/GCS/Aliyun adapter (httpx REST for aliyun; s3/gcs via minimal signed request or existing http). No new heavy dep if aliyun works via REST; otherwise `boto3`-equivalent is acceptable.
- [ ] **M4.2:** envelope-encryption wrapper — root KMS per region wrapping a per-vault data key; object file never cleartext.
- [ ] **M4.3:** startup pull — nearest region; miss → primary; cache `vault_mtime`.
- [ ] **M4.4:** conflict — latest mtime wins + write-lock; refuse concurrent rotate with a clear error.
- [ ] **M4.5:** audit `admin_secret.replica_pulled|pushed` via `audit.py`.
- [ ] **M4.6:** config section `secrets.replication` in `config.yaml` + `.env.example` keys.
- [ ] **tests:** replicator adapter against a fake object-store; encrypt/decrypt envelope (round-trip); conflict refusal; DR drill (kill primary, gateway in secondary serves within 60s) simulated with a stub second region.
- [ ] **Consideration:** flag as **read-mostly**; rotate stays single-writer per region; network-partition rotate needs timeout + admin error. Document tradeoff in `docs/admin-secrets-multiregion.md`.

## Risks
- **M2 universal coverage** is the largest risk (thread/workflow/connector/quota all need gating) — keep each new gate additive with a deny-by-default that falls back to existing RBAC when no policy is loaded, so we don't break live tenant paths.
- **collab isolation** may have more than one leak surface — the autouse reset must cover `require_user` override AND `_service`; verify by running several full ABAC files in sequence, not just one.
- **better-auth/next dep bumps** must stay green through all of M5 — run the `next-config.test.ts` proxy suite after every frontend touch (already wired in the gate).
- **slack WS** — network-coupled in integration; keep a transport seam so unit tests avoid a real socket.
- **multi-region** — object-store creds in `.env`; keep reading path degraded-to-empty (existing behavior) so a KMS hiccup at cold start never 500s.
