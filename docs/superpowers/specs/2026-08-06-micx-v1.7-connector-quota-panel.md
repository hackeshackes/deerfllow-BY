# Roadmap Spec — Canvas Connector Quota Panel (v1.7)

**Date:** 2026-08-06
**Issue:** [#11](https://github.com/hackeshackes/deerfllow-BY/issues/11)
**Status:** backlog — grooming only, no implementation this iteration

## Problem

`POST /api/workflows/{id}/execute` persists per-execution usage (tokens in/out, executions count) via `UsageRecord` + `record_usage()`, but operators only see **aggregates** — there is no panel breaking usage down by user or workspace. Issue #11 asks for the operator-facing breakdown.

## Goals

- Per-user and per-workspace usage breakdown in the admin UI.
- Aggregation `GET /api/admin/quota/usage?group_by=user|workspace&since&until`.
- Drill-through from a row into the execution list for that user/workspace.

## Non-goals

- Changing the cost/quota enforcement logic (only the visibility/breakdown panel).
- Multi-region or realtime push.
- Pricing/currency work beyond existing `cost_calculator`.

## Proposed shape

### API

```
GET /api/admin/quota/usage?group_by=user|workspace&since=<iso>&until=<iso>&cursor&limit=25|50|100
→ { rows: [ { id, name, tokens_in, tokens_out, executions, last_active_at } ], next_cursor, total }
```

- Aggregate over all `UsageRecord`s via a new `UsageTracker.aggregate(by, since, until)`.
- Cursor pagination; empty-state `{ rows: [] }` when no usage.

### Frontend

- New admin page `quota-usage-page.tsx` under `admin-page-shell`.
- Group-by toggle (user / workspace), date-range filter, pagination (25/50/100 + cursor), row → drill-through detail view of that scope's executions.

## Acceptance criteria

- [ ] Aggregation correctness cross-checked against raw `audit.jsonl` usage events (test).
- [ ] Empty-state renders (`no usage yet`), no crash.
- [ ] Pagination 25 / 50 / 100 + cursor.
- [ ] Date-range filter.
- [ ] Drill-through detail view per user/workspace.

## Affected files (reference)

- `backend/app/gateway/multitenancy/usage_tracker.py` — add `aggregate(by, since, until)`
- `backend/app/gateway/multitenancy/router_service.py` — new router + schema
- `frontend/src/components/workspace/admin/quota-usage-page.tsx`

## Open questions

- Default date window when `since`/`until` omitted.
- Whether drill-through should filter to a single `workflow_id` too.
